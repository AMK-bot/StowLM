# Production KCS longitudinal strength (D20 / D22)

The approved design method is implemented in strength_limits.py and follows
current dimensions/DB heights rather than the rounded example values. Current
capacity outputs are `envelopes.json` and the three `feeder_*.csv` files,
regenerated by `generate.py` using production vessels;
`full_load.py` generates `full_load.json` with empty tank contents.
The `approved-*` files retain the earlier diagnostic calculation for comparison.

Hull-following tanks now use task2.1's `section_liquid_areas` at the coupled
hull/liquid equilibrium heel and trim. APPROXIMATION: each wet section contributes
a concentrated mass equal to density times wet area times its longitudinal
quadrature weight. This preserves tank mass and longitudinal first moment
exactly in the supplied representation. It does not invent panels across
gaps or unmatched Gauss stations. SF has corresponding station jumps; continuous
SF inside gaps cannot be inferred from this geometry (see vessel/hull_tanks.py).
Rectangular tanks retain exact piecewise-quadratic distributed loads. No tank
uses uniform bounding-box loads as a substitute for hull-following geometry.

Production integration tests include a nonempty hull-following tank, in addition
to independent gapped/nonuniform section tests at empty/full and tilted fills.
Strength-only homogeneous results do not certify stability or any loading plan.

## Geometry inputs and AP/FP overhangs

The strength-limit builder no longer reads any retired analytic hull-form
coefficients. Lpp, beam and depth come from HullGeometry and are checked against
the built HullModel; scantling draught comes from HullModel. Integrated immersed
volume and waterplane area give Cb and Cw at scantling draught, including all
retained source overhangs. Hull-form metadata is used only to construct the
checksum-pinned source geometry.

S11A bow flare is `(A_DK-A_WL)/(0.2L*(D-T))`. A_DK and A_WL are integrated
bare-hull polygon deck/waterline widths over 0.8L..L; appended coamings are
excluded. APPROXIMATION: widths are reconstructed linearly inside each two-point
Gauss panel. Complete panels preserve Gauss weights exactly; partial boundary
panels are integrated analytically rather than cropping Gauss nodes. Independent
trapezoidal-section tests verify area, partial-panel treatment and exclusion
of a deliberately broad coaming.

KCS source stations extend from -6 to 236.9 m for reference Lpp=230 m; the
transformed production ships retain the scaled overhangs. The beam starts and
ends at those actual source panel boundaries. Weight, buoyancy, Gauss weights,
readouts and affine closure all use that complete span. AP/FP are interior cuts:
their SF/BM need not vanish. New closed-form tests verify nonzero AP/FP cuts
and zero physical-end reactions without discarding any buoyancy.

APPROXIMATION: the rule length remains Lpp because S2 measurements are absent.
S11A wave diagrams only define 0..L; extend their AP/FP endpoint allowances and
assumed end scantlings constantly over each overhang. The CSV explicitly stores
`wave_rule_x_m`, distinct from the actual readout `x_m`. This structural
extension is a synthetic assumption, not a class-approved overhang design.

## D22 residual structural capacities

Authority: local `data/raw/iacs/ur-s11a.pdf` (June 2015), §§2.3.1–2.3.3,
Figs.6–7 and §3.3; UR S7.1 Rev.4 May2010 in `URS-2024.pdf`, PDF p32.
The [official consolidated IACS source](https://iacs.s3.af-south-1.amazonaws.com/wp-content/uploads/2024/09/17130516/URS.pdf)
and hashes are recorded in the adjacent MANIFEST. S7's page was visually checked:
`Zmin=c L² B (max(Cb,.60)+.7) k` is in cm³, converted by 1e-6 to m³.
Use the new-ship coefficient, ordinary mild steel ReH=235 MPa and k=1.
S11A permissible bending stress is sigma=235/1.24 MPa, pure shear
stress tau=235/(1.13 sqrt(3)) MPa. Fig.7's lower curve starts at 0.25 F_sag_aft
at AE and reaches zero at FE; model SF signs are the opposite of S11A.

APPROXIMATION: the design still-water reserve is recovered from the old
UR S11 requirement implicit in S7's minimum. Old S11 excludes container ships;
these are synthetic design loads, not container-ship permissible limits. With
Cb_r=max(Cb,.60), Q=c L² B (same new-build c as S7), in N*m:

- M_sw,hog,design = Q (122.5 − 15 Cb_r);
- M_sw,sag,design = 65 Q (Cb_r+.7).

APPROXIMATION: assume uniform effective net
`Z=1.10*max(Zmin,(M_wave,hog+M_sw,hog,design)/sigma,
(|M_wave,sag|+M_sw,sag,design)/sigma)`.
This preserves the 1.10 design margin and the exact S11A stresses/wave loads.
At the previous 8.25 m feeder_500 depth, the reference Z values are
approximately 4.730 / 6.417 / 12.842 m³. Actual values follow current geometry:
changing depth changes KCS bow flare, waves and the governing Z requirement.
Permissible SWBM remains sigma Z minus the appropriate signed wave envelope.

APPROXIMATION: mild-steel gross side shell is (8+.04L) mm and inner skin is
(6.5+.03L) mm. Deduct 1.25 mm for hull-girder net properties using S11A §1.3's
0.5*(1.0+1.0+0.5) corrosion allowance. The gross thickness formulae are design
assumptions, not verified class minimum-thickness rules. The double-bottom
height h_db is read from hull.double_bottom_height_m when supplied, otherwise
from the low WB-series DB tank tops; this is a labelled structural proxy.

APPROXIMATION: effective midbody reference shear area is
`A_ref=.95*2*(t_side,net*D+t_inner,net*(D-h_db))`.
The .95 effectiveness represents the I*sum(t)/S reduction of an idealised
double-skin section. Lumped flanges, missing coaming/longitudinal details and
ignored local-load delta-F remain approximations. As the approved derivation
requires, retain a lower bound of 1.10 times the pure-wave area requirement;
no cargo or utilization result enters this calculation.

APPROXIMATION: longitudinal shear strakes use a piecewise-linear profile:

| x/L | 0 | .10 | .15 | .30 | .40 | .60 | .70 | .85 | .90 | 1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| p(x/L) | .60 | .85 | 1.20 | 1.20 | 1.00 | 1.00 | 1.20 | 1.20 | .85 | .60 |

This preserves full midbody plating and +20% quarter-point strakes. The exact
wave/profile maximum lies at the merged piecewise-linear knots. Subtract each
signed S11A wave shear envelope from tau*A_ref*p(x/L). Reference area means
midbody area, not peak area. Limits are not tuned for a training signal or to
make a loading condition pass. No combined yielding, buckling, ultimate
capacity, actual shear-flow or classification approval is claimed.

At L=107.8, D=9.2 and h_db=1.2 m the stated formula gives A_ref=0.322321 m²,
rather than the design note's illustrative 0.320; no rounded target is forced.
A different DB height in the final params naturally changes this value.

## Integration approximations and condition coverage

APPROXIMATION: cargo acts at 20-foot cell centres, splitting 40/45-foot mass
between cells, rather than at corner castings. Lightship is uniform inside
declared blocks; its supplied distribution folds beyond-perpendicular weight
inside AP–FP. Buoyancy reconstruction is panel-linear and preserves Gauss
force and first moment. All actual Gauss nodes, physical ends, AP/FP, a 1%-L
grid, rule corners and proxy hold boundaries remain read-out points.
APPROXIMATION: coaming ends/centres proxy unsupplied bulkhead frames; positions
are not Society-approved.

The physical raw trim moment is `-W*(KG-KB)*(T_aft-T_fwd)/Lpp`, using the final
coupled liquid/ship CG. Only the numerical remainder is tested by the synthetic
0.1% guard; a physical trim couple is not a strength violation. Numerical
imbalance prevents a verdict. APPROXIMATION: the affine curve-closing shape
still replaces the actual distributed trim couple. Raw, predicted, numerical
and corrected end values are exposed, with physical beam boundaries as metrics.
Dry open covers relocate weight; immersed open lips need flooding geometry.

APPROXIMATION: each invocation checks the supplied condition against seagoing
limits. Departure-only orchestration does not meet S11A §2.2.2's arrival/worst
intermediate-condition coverage or define harbour limits. The full-checker owner
must handle that gap. Strength-only acceptance never certifies a loading plan.

## Reproduction and verification

```sh
export UV_CACHE_DIR=$PWD/.uv-cache
export STOWAGE_VESSEL_CACHE_DIR=/private/tmp/stow-strength-vessels
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
uv run python experiments/strength/generate.py
uv run python experiments/strength/full_load.py  # currently blocked by tank assembly
uv run python experiments/strength/empty_tank_probe.py  # explicit diagnostic, empty tanks
uv run pytest -q tests/checker/test_strength*
```

Disposable, source-fingerprinted vessel caches store complete production builds;
no hull is substituted on a cache miss. One CPU thread, no GPU, expected <1 GB.
Cold table construction takes about one to two minutes per ship; see `compute.md`.

The full-load condition has a 10-t box in every compatible 20-foot cell, no tank
contents, and supplied lightship/fixed loads. Results below are strength-only;
other checkers can reject the same condition. Limits are not tuned to pass it.
