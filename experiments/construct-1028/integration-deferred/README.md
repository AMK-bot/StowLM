# Deferred integration

The production scalable and two-step integration was manually reverted because
the standalone constructive campaign has no passing candidate (0/32), and a
known-checker-passing tiny witness is infeasible under the conservative source
physics model. Mechanical tests alone cannot establish the new production path.

Before-revert production file copies, the six integration tests and their
verification note are archived here with `archive-manifest.json` SHA-256 hashes.
The `.py.txt` suffix keeps archived tests out of automatic test collection.
The live six-test integration file was removed after archiving. No other owner's
files were removed or reverted; no git state-changing command was used.

Restoration requires a positive checker/shipping/token-mask production witness
and a new verification of the integration under the final constructor model.
Proposed production scalable/two-step version bumps are now **none**. The
standalone experimental constructor remains available.
